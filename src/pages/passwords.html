Passwords and autofill

Opal doesn't save passwords yet

Opal is built on Electron, which doesn't include Chrome's password manager or autofill. Rather than store your passwords in a home-made vault, Opal leaves them alone.

For now, use your password manager's desktop app, or its browser extension once extensions are set up (Settings > Extensions). Your browser's built-in form memory for simple fields still works.

Opal AI never reads or types saved passwords.
